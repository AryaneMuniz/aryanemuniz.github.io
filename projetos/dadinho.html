What I builtO que eu fiz

A Copilot Studio agent the Natura & Avon team calls in Teams. It uses a data catalog and a verified FAQ as knowledge, with rules to never make things up and to point to the right team when it doesn't know.Um agente no Copilot Studio que o time de Natura & Avon chama no Teams. Usa um catálogo de dados e um FAQ verificado como conhecimento, com regras para nunca inventar e indicar o time certo quando não sabe.

How it worksComo funciona

  1. The team mentions the agent in Microsoft Teams.O time chama o agente no Microsoft Teams.
  2. It answers from a data catalog and a verified FAQ.Ele responde a partir de um catálogo de dados e de um FAQ verificado.
  3. When it doesn't know, it says so and points to the right team.Quando não sabe, avisa e indica o time certo.
