The problemO problema

Media teams keep asking which creative features drive CTR, and paid tools send the creatives outside the company.Os times de mídia sempre perguntam quais características dos criativos puxam o CTR, e as ferramentas pagas mandam os criativos pra fora da empresa.

What I builtO que eu fiz

An open-source Python tool that tags each creative (face, product, CTA, color, format) and measures how much each feature changes CTR, CPM and CPC, isolating each effect with a regression that controls for country and corrects for multiple testing. Validated on synthetic data with planted effects and deliberate statistical traps, it ships a data contract ready for BigQuery, a vision-AI tagger, an MCP server with six tools for AI agents and a dashboard hub published automatically to GitHub Pages.Uma ferramenta em Python, de código aberto, que etiqueta cada criativo (rosto, produto, CTA, cor, formato) e mede quanto cada característica muda o CTR, o CPM e o CPC, isolando cada efeito com uma regressão que controla o país e corrige para muitos testes. Validada com dado sintético, efeitos plantados e armadilhas estatísticas montadas de propósito, entrega um contrato de dados pronto pro BigQuery, um etiquetador com IA de visão, um servidor MCP com seis ferramentas para agentes de IA e um hub publicado sozinho no GitHub Pages.

How it worksComo funciona

  1. Generates creatives and daily media with planted effects (the answer key).Gera criativos e mídia diária com efeitos plantados (o gabarito).
  2. A tagger reads each creative: face, product, CTA, color and format.Um etiquetador lê cada criativo: rosto, produto, CTA, cor e formato.
  3. Isolates the effect of each feature on CTR, CPM and CPC with a regression (country as a control, one vote per creative, Benjamini-Hochberg correction), with 95% intervals and filters by country, platform and period.Isola o efeito de cada característica no CTR, no CPM e no CPC com uma regressão (país como controle, um voto por criativo, correção de Benjamini-Hochberg), com intervalo de 95% e filtros por país, plataforma e período.
  4. Exports two tables in a data contract ready for BigQuery.Exporta duas tabelas num contrato de dados pronto pro BigQuery.
  5. Publishes a hub with tabs to GitHub Pages on every merge, and answers AI agents through MCP.Publica um hub com abas no GitHub Pages a cada merge e responde agentes de IA via MCP.

EngineeringEngenharia

226 automated tests across 28 pull requests, CI on every pull request and a protected main branch. Four simulated traps (confounding, Simpson's paradox, a dominant creative and false alarms) fool the simple analysis and are passed by the regression. Tested end to end as a user, on desktop and mobile.226 testes automáticos em 28 pull requests, CI em todo pull request e main protegida. Quatro armadilhas simuladas (confusão, paradoxo de Simpson, peça dominante e alarme falso) enganam a análise simples e são resolvidas pela regressão. Testado de ponta a ponta como usuária, no computador e no celular.
